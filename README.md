# ummado

엄마도 — AI 모델 비교 플랫폼

한국의 유명한 밈 프롬프트를 Claude, Gemini, ChatGPT, Grok이 어떻게 해석하는지 비교해보세요.

## 개발 시작

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인

## AI 응답 가져오기

프롬프트가 준비되고 API 키가 설정되면:

```bash
npm run fetch:models
```

## 환경 설정

`.env.local` 파일을 생성하고 `.env.example`의 변수들을 입력하세요.

## 빌드

```bash
npm run build
npm start
```

## 테스트

```bash
npm test
npm run typecheck
npm run lint
```
